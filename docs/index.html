🚀

۱۰۰٪ بدون سرور (Serverless)

بدون نیاز به بک‌اند Node.js، PHP یا جنگو. تمام درخواست‌ها به صورت مستقیم و امضا شده با کلید S3 انجام می‌شوند.

📱

پوشش چند پلتفرمی کامل

دارای اپلیکیشن نیتیو اندروید با Jetpack Compose، کلاینت پرتابل ویندوز، و ابزار اسکریپت‌نویسی خط فرمان (CLI).

🛡️

ایمن در برابر تداخل (Race-Safe)

لایک‌ها و کامنت‌ها فایل‌های اتمیک جداگانه دارند (مانند like_ali.txt)؛ بنابراین ارسال همزمان چند کاربر تداخلی ایجاد نمی‌کند.

⚡

معماری آفلاین-فرست (Offline-First)

اپلیکیشن اندروید تمام داده‌ها را در دیتابیس Room گوشی کش می‌کند تا در هر شرایطی فید به سرعت باز شود.

🔒

حریم خصوصی اختصاصی حلقه

دسترسی تنها با کلیدهای API باکت با امضای HMAC-SHA256 انجام می‌گیرد و داده‌ها خارج از باکت شما درز نمی‌کند.

🎨

پوسته‌های دارک و لایت مدرن

رنگ‌بندی ایندیگو و فیروزه‌ای چشم‌نواز با پشتیبانی پیش‌فرض از دارک مود در تمام کلاینت‌ها.

زیر ذره‌بین مهندسی

معماری مستقیم به S3 بدون دیتابیس

چگونگی چینش پست‌ها، پیوست‌های رسانه‌ای، کامنت‌ها و لایک‌ها در باکت آبجکت استوریج آروان‌کلاد.

📁 فایل‌های JSON و تصاویر

هر پست یک فایل JSON مستقل همراه با فایل تصویر باکیفیت در پوشه /posts/ ذخیره می‌شود.

💬 کامنت‌های تفکیک شده

کامنت‌های هر پست در یک پوشه اختصاصی با شناسه همان پست (/comments/<post_id>/) ذخیره می‌شوند.

🛡️ نشانگرهای لایک اتمیک

هر لایک یک فایل متنی سبک است. متدهای PutObject و DeleteObject در S3 اتمیک و بدون تداخل هستند.

راه‌اندازی ساده

۴ گام برای ساخت شبکه خصوصی شما

ساخت باکت در پنل آروان‌کلاد کمتر از ۲ دقیقه زمان می‌برد. مشخصات را به اعضای گروه بدهید و استفاده کنید.

۱

ساخت صندوقچه خصوصی

به پنل آروان‌کلاد -> فضای ابری رفته، روی صندوقچه جدید کلیک کرده و دسترسی را خصوصی بگذارید.

۲

دریافت آدرس S3 Endpoint

آدرس اندپوینت منطقه خود را کپی کنید (مثلاً https://s3.ir-thr-at1.arvanstorage.ir).

۳

ساخت کلیدهای API

در بخش API Keys یک کلید خواندن و نوشتن ساخته و آن را به صندوقچه متصل (Attach) کنید.

۴

ورود اطلاعات در برنامه

این ۴ مشخصه (نام باکت، اندپوینت، Access Key، Secret Key) را در اپلیکیشن وارد کنید.
